# DNJ 2026

Página única com a arte do encontro, a música Jesus Christ, You Are My Life, o áudio original do Papa Leão XIV, tradução em português do Brasil e a Oração do Jovem.

## Publicar no GitHub Pages

1. Crie um repositório público chamado `dnj-2026` no GitHub.
2. Extraia este ZIP. Envie o conteúdo da pasta `dnj-2026` para a raiz do repositório, mantendo a pasta `assets`.
3. Abra **Settings → Pages**.
4. Em **Build and deployment**, escolha **Deploy from a branch**.
5. Selecione a branch **main** e a pasta **/(root)**, depois **Save**.
6. Aguarde a publicação e copie o endereço exibido pelo GitHub Pages.
7. Teste os dois áudios no celular antes de gravar esse endereço como registro URL na tag NFC.

A página precisa de internet para carregar os arquivos. A reprodução começa quando o visitante toca no controle do áudio. Apenas um áudio toca por vez. Todos os arquivos de mídia usam caminhos relativos compatíveis com GitHub Pages.

## Tradução

A tradução em texto usa o parágrafo dirigido aos jovens da audiência geral de 4 de junho de 2025 como referência. Fonte: https://www.vatican.va/content/leo-xiv/it/audiences/2025/documents/20250604-udienza-generale.html

O áudio original foi mantido sem edição. A tradução não é uma dublagem.
